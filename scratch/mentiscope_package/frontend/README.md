# 🎨 Mentiscope Frontend Client
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Motion (Framer Motion)
- **Icons**: Lucide Icons
- **Data Viz**: Recharts + Custom SVG Visualizers

### Local Development:
```bash
npm install
npm run dev
```

### Production Build:
```bash
npm run build
```
Static production output will be generated in `dist/`.
